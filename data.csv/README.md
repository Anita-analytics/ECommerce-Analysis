# 🛒 E-Commerce Sales Intelligence

## 📌 Objective
Analyzed 400K+ e-commerce transactions to uncover revenue 
trends and built a Machine Learning model to predict revenue.

## 📊 Dataset
- Source: UCI Machine Learning Repository
- Total Transactions: 400,000+
- Countries: 38+
- Time Period: 2010-2011

## 🔍 Analysis Performed
- Data Cleaning
- Top 10 Best Selling Products
- Country Wise Revenue Analysis
- Monthly Revenue Trends
- Top 10 Customers by Revenue
- Day Wise Sales Analysis
- ML Model — Linear Regression
- SQL Queries (10 queries)

## 💡 Key Insights
- UK is the #1 revenue market
- November is the peak sales month
- Thursday has highest sales volume
- ML model predicts revenue accurately

## 🛠️ Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (ML)
- MySQL (SQL Queries)
- VS Code
